# Contributing

Bug reports and small fixes are welcome as issues and pull requests.

- `make test` and `make lint` pass ([docs/development.md](docs/development.md)).
- A change to how blocks behave comes with a test in `tests/`.
- Comments only where the code cannot say it: formulas, sources, reasons.

By contributing you agree that your contribution is licensed under GPL-3.0-or-later.
